# Créditos, fuentes y linaje

## Referencias históricas conservadas

- **maximaas/MegaBurner:** base del programador para MX29L3211/Arduino Mega y aplicación original Java/SWT.
- **sanni/cartreader — Open Source Cartridge Reader:** antecedente de lógica de lectura/programación de flash paralela.
- **mkeller0815/MEEPROMMER:** antecedente de comunicación serial PC-Arduino.
- **Macronix:** datasheets de MX29L3211, MX26L6420 y MX29LV160C; consultar documentación oficial para tensión, ID y programación.
- Imágenes históricas de origen referenciado por el ZIP v0.5A: [`megaburner_hw.png`](archive/MegaBurner_WebSerial_v0_5A/docs/assets/original-megaburner/megaburner_hw.png) y [`megaburner_window.png`](archive/MegaBurner_WebSerial_v0_5A/docs/assets/original-megaburner/megaburner_window.png). No representan el shield R4.9.

## Linaje técnico vigente

- Perfil MX29L3211: base en `baselines/MX29L3211_v0_5A` (page program).
- Perfil MX26L6420: base en `baselines/MX26L6420_v0_1` (word program).
- Perfil MX29LV160CT: implementación nueva por datasheet; hardware físico pendiente.
- PCB actual: `hardware/pcb/R4.9-2L-FINAL` con archivos originales, proyecto editable PCB-only y validaciones adjuntas.

La licencia del proyecto integrado conserva el archivo [`LICENSE`](../LICENSE) de la v0.7A. Consultar también los avisos originales de las dependencias; este paquete de integración **no reemplaza** sus créditos ni afirma propiedad sobre imágenes/fuentes previas. Se preserva el historial íntegro en [archivo de documentación](archive/MegaBurner_WebSerial_v0_5A/ARCHIVE_README.md).
